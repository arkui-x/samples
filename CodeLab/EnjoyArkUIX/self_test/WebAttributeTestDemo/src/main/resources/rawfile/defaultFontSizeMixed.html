1. 仅指定 font-size 样式（12px）

ABCDEFG abcdefg 0123456789

这段文字显式设置 font-size:12px，不受 defaultFontSize 影响，应保持 12px。

2. 仅使用 monospace 字体

ABCDEFG abcdefg 0123456789

这段文字使用 monospace 字体，未设置 font-size，观察 defaultFontSize 是否生效。

3. monospace 字体 + 指定 font-size（12px）

ABCDEFG abcdefg 0123456789

这段文字同时使用 monospace 字体与显式 font-size:12px，应保持 12px。

4. 两者都没设置（默认字体/字号）

ABCDEFG abcdefg 0123456789

这段文字未设置 font-family 与 font-size，字号应受 defaultFontSize 属性控制。
